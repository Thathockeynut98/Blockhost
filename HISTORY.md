# Development history and provenance

This repository was **reconstructed from eight preserved BlockHost release archives**. Each `archive:` commit records the complete files available for that release, in version order. These are new reconstruction commits, **not recovered original commits**, and their dates reflect reconstruction rather than original development. Original commit messages, authorship metadata, and intermediate changes not present in the ZIPs cannot be recovered.

Snapshots: v1, v2, v3, v4, v5, v6, v6.1, v6.2. Compare tags in GitHub to review source changes between preserved versions.
